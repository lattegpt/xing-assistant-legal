适用范围与运营主体

本政策适用于比邻星跨境贸易有限公司运营的“星助手”（比邻星内容助手）接入 Meta 平台的账号授权、内容管理、广告管理及报表功能。应用编号：1401416684879798。本说明同时适用于获授权的员工、团队管理员及通过本服务管理平台资产的用户。具体处理以实际启用的功能和授予的权限为限。

我们处理的信息

账号和资产信息：授权用户或系统用户标识、名称、业务资产组合、广告账户、公共主页、Instagram 或 Threads 账号标识，以及授权权限和有效状态。

授权凭证：用于调用已授权功能的访问口令及必要的授权记录。口令属于机密凭证，不作为公开资料展示。

素材与业务信息：你提供的姓名、工作联系信息、素材邮件正文和附件、视频、图片、广告文案、投放地区及广告中使用的业务联系电话或 WhatsApp 号码。

广告与效果信息：广告系列、广告组、广告、创意、视频标识、预算及投放状态，以及花费、展示、点击、消息对话成效等平台返回的统计数据。

内容和互动信息：仅在相应功能启用并获得权限时，处理发布的内容、发布回执和互动统计；消息管理功能启用时，还可能处理获授权主页或专业账号的消息正文、发件方标识、时间及回复记录。

操作与安全信息：授权、上传、创建、暂停、查询、删除申请和错误处理的时间、结果及必要的技术日志。

处理目的

用于核验资产访问权限、匹配员工与素材、按授权上传内容或创建广告、查询效果和展示报表，以及执行管理员已启用的广告管理规则（例如 CPA 超标暂停）。日志用于核验平台结果、处理错误和避免重复操作。数据不会用于出售个人信息或建立与上述用途无关的个人画像。广告成效中的消息对话次数属于平台统计，不等于经核验的独立客户人数。

授权与选择

仅处理你有权提供或管理的信息。你可以不启用某项功能、拒绝非必要权限，或在 Meta 提供的业务集成、应用或资产设置中撤销相应授权。撤销授权可能使相关功能无法继续使用，但不影响撤销前合法进行的处理。已经上传到 Meta 的内容及广告状态不会因撤销口令自动删除或停止，请在对应平台确认。

共享、服务商与跨境处理

执行已授权操作时，必要的账号标识、内容素材、文案和广告配置会通过 Meta 的接口传输至 Meta 并受其规则约束。Meta 可能在境外处理这些数据。我们使用的托管、存储和邮件服务商仅在提供相应服务所需范围内处理信息；当前基础设施包括腾讯云，素材邮件服务包括飞书邮箱。本站公开说明页由 GitHub Pages 托管，GitHub 可能处理访问该页面所需的网络地址及技术访问日志；本站不嵌入广告追踪脚本。除获得授权、提供服务所必需或法律要求外，不向无关第三方披露个人信息。

保存与安全

账号映射、素材、报表和操作记录在提供已启用的管理、追溯及安全功能所必需的期间保存。仅撤销授权或隐藏素材，不等同于立即删除已有记录。需要完整删除时，请通过下述邮箱提出申请；我们将核验身份并处理，依法必须保留的记录会限制用途和访问。不会宣称系统具有尚未实现的定时自动删除功能。

我们采用访问控制、HTTPS 传输、授权凭证保护和操作审计等措施。Meta API 授权使用访问口令，不要求用户通过本政策网站提供 Meta 密码或双重验证秘钥。请勿在删除申请中发送密码、口令或验证码。
